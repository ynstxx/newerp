# 信息化集成企业管理系统

面向系统集成公司的全流程管理系统：设计 → 施工 → 验收 → 质保 → 售后。

- **零 Web 框架、零 ORM**：HTTP 层、SQL 层、迁移器、校验、分页全部手写
- **运行时依赖只有两个**：`pg`、`mysql2`
- **双库等权**：PostgreSQL 16+ 或 MySQL 8.0+，CI 矩阵两项都跑
- **多租户**：共享库共享表 + `tenant_id`，跨租户引用物理上不可能
- **许可证**：AGPL-3.0

唯一权威文档：[`docs/DESIGN.md`](docs/DESIGN.md)（v0.4）
